# Weather App

A simple, responsive weather application built with HTML, CSS, and JavaScript.

## 📖 About

This project is a front-end weather app that allows users to check current weather conditions. It fetches real-time weather data and displays it in a clean, user-friendly interface. The app is designed to work seamlessly on both desktop and mobile devices.

> **Note:** This repository contains the front-end code. You may need to configure an API key from a weather service provider (e.g., OpenWeatherMap) for the app to fetch live data.

## ✨ Features

- **Real-time Weather Data** – Displays current temperature, weather conditions, humidity, wind speed, and more.
- **Search by City** – Users can search for weather information by city name.
- **Responsive Design** – Optimized for mobile, tablet, and desktop screens (see `style.css` fix for mobile view).
- **Clean UI** – Simple and intuitive layout for a smooth user experience.

## 🛠️ Technologies Used

- **HTML5** – Structure of the app (`index.html`)
- **CSS3** – Styling and responsive design (`style.css`)
- **JavaScript** – Logic and API integration (likely embedded or linked within `index.html`)
- **Assets** – Icons and images stored in the `asset` folder
